## About DoseMate

DoseMate is a modern, responsive medication management platform designed to help people organize their medicines, create personalized medication schedules, receive reminders, and track their daily doses.

The platform aims to make everyday medication management simpler through an intuitive interface and accessible digital experience.

## ✨ Key Features

- **Medicine Management** – Add, organize, edit, and manage medicines.
- **Medicine Photo Upload** – Upload medicine photographs for easy reference.
- **Custom Scheduling** – Set medication dates, times, and recurring schedules.
- **Medication Reminders** – Get notified when scheduled doses are due, where supported.
- **Dose Tracking** – Record taken, skipped, and missed doses.
- **Medication History** – Review previous medication records.
- **Notification Centre** – Manage medication reminder notifications.
- **Dark & Light Mode** – Switch between beautifully designed themes.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dosemate.git
```

Navigate to the project directory:

```bash
cd dosemate
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```text
http://localhost:3000
```

Configure the required environment variables using `.env.example` before connecting external services.

## 🔐 Privacy & Security

DoseMate handles medication-related information. Users should verify all medicine names, dosage instructions, and schedules against their prescriptions or healthcare professional's instructions.

Never commit API keys, passwords, database credentials, or `.env` files to GitHub.

## ⚕️ Important Disclaimer

DoseMate is a medication organization and reminder platform. It does not provide medical diagnoses, prescribe medicines, or replace professional medical advice.
